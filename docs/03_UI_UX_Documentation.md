# Document 3 — UI / UX Documentation

## Out of Scope for the HADES Model-Development Prototype

Status: Out of scope

---

## 1. Why this document is empty

This project is currently scoped to **model development only**: building and training the HADES architecture (`project_HADES.md`) against a leakage-safe supply-chain graph, to validate its four design claims (`10_AI_ML_Documentation.md` §1). There is no frontend, no dashboard, and no interactive UI being built — nothing in this project renders a screen.

This document previously specified 22 screens (login, risk dashboard, graph visualization, chatbot, what-if simulator, approval queue, alerts, admin, and others) for a full product build. None of that is being built right now, so none of it is documented here — a stub with unmaintained screen specs would be more misleading than an honest placeholder.

## 2. If this work resumes

If the product build (dashboard, chatbot, approval workflows) is picked back up later, `architecture.md` (Section 4.2, Layer 6 — Frontend Dashboard) and the git history of this repository are the reference points, not this document — it does not carry forward stale screen specs from before the rescope.

- **`10_AI_ML_Documentation.md`** — what is actually being built.
- **`14_Model_Development_Roadmap.md`** — the order it's being built in.
- **`project_HADES.md`** — the full architectural specification driving all of it.
